# EduSphere AI 🎓

An AI-powered educational assistant built using Python and Streamlit.

## Features
- AI-powered chatbot
- User registration and login
- Secure password hashing
- Chat history management
- Document Assistant for PDF and TXT files
- AI Quiz Generator
- Light and Dark themes
- Gemini AI with Ollama local AI backup

## Technologies Used
- Python
- Streamlit
- Google Gemini API
- Ollama (Llama 3.2)
- SQLite
- HTML and CSS

## Installation

1. Clone or download this repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Create a `.env` file:

   `GEMINI_API_KEY=your_new_api_key`

4. Run the application:

   `streamlit run app.py`

## Security
Never share your API keys, passwords, or private database files.
